# 更新流程文档

## 1. 代码更新流程

### 1.1 本地开发
1. 使用 Git 客户端（GitHub Desktop/SourceTree）：
   - 确保在正确的分支
   - 拉取最新代码
   - 创建功能分支
   - 开发功能
   - 提交代码
   - 推送到远程

### 1.2 代码合并
1. 在 GitHub 上创建 Pull Request
2. 进行代码审查
3. 合并到 develop 分支

### 1.3 部署到生产环境
1. 合并到 main 分支
2. 在服务器上更新：
   - 拉取最新代码
   - 安装依赖
   - 重启服务

## 2. 版本控制

### 2.1 版本号规则
- 主版本号：重大更新
- 次版本号：新功能
- 修订号：bug修复

### 2.2 发布流程
1. 更新版本号
2. 更新更新日志
3. 创建发布标签
4. 部署到生产环境

## 3. 回滚流程

### 3.1 代码回滚
使用 Git 客户端：
1. 查看提交历史
2. 选择要回滚的版本
3. 执行回滚操作

### 3.2 数据库回滚
1. 使用备份恢复
2. 执行数据库迁移

## 4. 监控和日志

### 4.1 服务监控
- PM2 状态
- 系统资源
- 错误日志

### 4.2 日志管理
- 应用日志
- 错误日志
- 访问日志
